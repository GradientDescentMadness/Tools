# Automatic Agentic JobApplicator - GUI Interface

> **Status:** 🚧 **In Progress**

The Graphical User Interface (GUI) desktop application for the Automatic Agentic JobApplicator is currently under active development and will be released in the upcoming update.

### Planned Features:
- 🖥️ **Interactive Desktop Dashboard:** Load, edit, and validate `resume_data.yaml` and `qa_rules.yaml` without opening raw text files.
- 📬 **Visual Outlook Mailer Scanner:** View detected LinkedIn job notification emails in an interactive grid with one-click preview.
- 🌐 **Embedded Application Webview:** Side-by-side view showing the live ATS browser session alongside the agent's real-time action feed.
- 🧠 **LLM Question Resolution Panel:** Review and approve AI-generated long-form answers and cover letter variations on the fly.
- 🎯 **One-Click Human Handover:** Big, accessible controls to pause, intervene, autofill individual sections, and confirm submissions.
