# Tools

A curated collection of utility tools, automation scripts, and security applications.

---

## Repository Contents

### 1. [PDF Security redactor](./PDF%20Security%20redactor/)
A permanent PDF sanitization and redaction utility built using `PyMuPDF`. Supports true binary scrubbing of sensitive PII, passwords, and confidential data.
- **[Python Source](./PDF%20Security%20redactor/Python%20Source/):** Interactive CLI version with step-by-step terminal prompts.
- **[GUI](./PDF%20Security%20redactor/GUI/):** Graphical desktop application with file browser, interactive term manager, and redaction style selector.

See the [PDF Security redactor README](./PDF%20Security%20redactor/README.md) for full documentation, security details, and usage guides.

---

### 2. [Automatic Agentic JobApplicator](./Automatic%20Agentic%20JobApplicator/)
An intelligent, semi-autonomous assistant that automates repetitive ATS job application portals (Workday, Oracle Cloud/Taleo, etc.) from LinkedIn email notifications or direct URLs. Features fuzzy skill dropdown matching, location-aware visa/citizenship questionnaire resolution, and strict human-in-the-loop safeguards before final submission.
- **[Python Source](./Automatic%20Agentic%20JobApplicator/Python%20Source/):** Full automated CLI workflow with Playwright browser engine, Microsoft Graph API email reader, and RapidFuzz matching.
- **[GUI](./Automatic%20Agentic%20JobApplicator/GUI/):** Graphical desktop dashboard *(in progress, coming in the next update)*.

See the [Automatic Agentic JobApplicator README](./Automatic%20Agentic%20JobApplicator/README.md) for architecture, configuration, and execution instructions.
